# Doots 🎺💀

My dotfiles I'm using on my different machines.

Tested and working on Ubuntu 24.04 LTS, Arch Linux, and macOS.

## Requirements

Basic requirements:

- autojump
- bat
- eza
- fish
- git
- stow

Extended requirements:

- lazygit (nvim)
- ripgrep (nvim)

## Installation

```bash
git clone [repo] ~/.dotfiles
cd ~/.dotfiles
stow [package]
```
